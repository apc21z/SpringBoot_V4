API REST

Información de endpoints; no son páginas navegables

API /api/books

GET lista y POST crea libros; cada libro incluye páginas como objetos con ID, título y texto.

API /api/books/{id}

GET consulta, PUT actualiza y DELETE elimina un libro y su lista de páginas.

API /api/people · /api/person

GET lista; POST crea; GET/PUT/DELETE por ID.

API /api/auth/register

POST registra un usuario.

API /api/auth/login

POST inicia sesión y devuelve el token.
